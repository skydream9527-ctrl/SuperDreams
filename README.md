## 🌟 Key Features

- **Full-Screen Home Screen Widget**: Quick access to news and tasks directly from your home screen.
- **News Feed**: Real-time aggregated news and updates.
- **Todo List**: Flexible task management with swipe-to-dismiss gestures.
- **Auto-Fill List**: Smart input suggestion and auto-completion for daily logs.

## 🛠️ Tech Stack & Architecture

- **Language**: Kotlin
- **UI Framework**: Android Jetpack / Material Design Components
- **Architecture**: MVVM (Model-View-ViewModel)
- **Async Processing**: Kotlin Coroutines & Flow

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/skydream9527-ctrl/SuperDreams.git
   ```
2. Open the project in **Android Studio (Koa / Ladybug or newer)**.
3. Sync Gradle dependencies and build the project.
4. Run on an Android Emulator or connected physical device (Android 8.0+ recommended).
